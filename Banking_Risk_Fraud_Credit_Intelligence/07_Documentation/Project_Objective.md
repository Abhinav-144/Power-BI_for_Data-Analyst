# Project Objective

## Project Name
Banking Risk, Fraud & Credit Intelligence Platform

## Problem Statement
Banking teams need to understand credit portfolio risk and transaction fraud patterns. This project develops a Power BI reporting solution that explores these two analytical areas using separate public datasets.

## Objectives
### Credit Risk
- Measure total loan applications and observed defaulted/non-defaulted records.
- Calculate the observed default rate.
- Compare default outcomes across loan grade, purpose, age band, employment length, and home ownership.
- Examine loan amounts, interest rates, applicant income, and loan-to-income ratios.

### Fraud Intelligence
- Measure total transactions and fraudulent transactions.
- Calculate the observed fraud rate and fraud transaction amount.
- Compare fraud counts and amounts across transaction amount bands.
- Explore fraud records by elapsed-time intervals.

### Reporting
- Provide an executive summary.
- Provide dedicated analytical pages for credit risk and fraud.
- Provide record-level investigation pages and drill-through navigation.
- Apply report interactivity through slicers, tooltips, and what-if analysis where configured.

## Intended Audience
The report is designed as a portfolio demonstration for audiences interested in banking analytics, credit risk analysis, fraud analytics, and business intelligence.

## Scope Boundaries
This project is descriptive and diagnostic. It does not build a predictive credit-scoring model, a live fraud detection engine, a real-time alerting workflow, or a customer-level unified banking model.
