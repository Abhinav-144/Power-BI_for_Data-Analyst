# Project Objective

## Project title
HR Workforce & Attrition Analytics

## Tool
Microsoft Power BI Desktop

## Project level
Basic to Intermediate

## Objective
Build an interactive HR analytics report that turns employee-level data into understandable views of workforce composition, compensation, tenure, employee attrition, satisfaction, and performance.

## Business questions
- How many employees are represented in the dataset?
- How is the workforce distributed across departments, job roles, age groups, and tenure groups?
- What is the overall attrition rate?
- Which departments, job roles, age groups, and overtime groups show higher attrition rates?
- How do job satisfaction, work-life balance, and environment satisfaction vary?
- How does average monthly income vary by department and job level?
- What actions could HR investigate based on the observed patterns?

## Deliverables
- Power BI report with five analytical pages plus a Business Insights page.
- Power Query cleaning and transformation documentation.
- DAX measure documentation.
- Business insights and recommendations.
- Screenshots and README for portfolio presentation.

## Dataset note
This project uses an IBM HR Analytics Employee Attrition & Performance-style dataset commonly used for learning. Do not claim it represents IBM's actual workforce.
